慈惠寺普渡 × 同樂70序曲｜GitHub 上傳步驟

一、建立 Repository
1. 登入 GitHub。
2. 按 New repository。
3. Repository name 可填：cihui-pudu-tongle70-mediapipe
4. 建議設為 Public。
5. 不要另外新增 README、.gitignore 或 License。
6. 按 Create repository。

二、用網頁直接上傳
1. 在新 Repository 頁面按 uploading an existing file。
2. 將本資料夾內所有檔案與資料夾拖曳進去。
3. 務必包含隱藏資料夾 .github。
4. Commit message 填：Initial MediaPipe version
5. 按 Commit changes。

三、啟用 GitHub Pages
1. 進入 Settings。
2. 左側點 Pages。
3. Source 選 GitHub Actions。
4. 回到 Actions，等待 Deploy to GitHub Pages 完成。
5. 完成後由 Settings → Pages 開啟網站網址。

四、測試
1. 用 Chrome 或 Edge 開啟網站。
2. 點「開始體驗」。
3. 允許相機權限。
4. 初次載入模型約需數秒。
